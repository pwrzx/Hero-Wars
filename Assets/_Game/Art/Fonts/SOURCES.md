# Game UI fonts

- Keep names and display headings use [Germania One](https://github.com/google/fonts/tree/main/ofl/germaniaone).
- Instructions use Oswald Regular from the 300Mind UI Kit. Actions and power numerals use the kit's Oswald SemiBold.

Germania One and Oswald include SIL Open Font License notices in this folder. The original Alegreya sources and their notices also remain here.

`Tower Trials > Prepare UI Fonts` bakes the three static TextMesh Pro font assets in `Assets/_Game/Resources/Fonts`. The action font uses equal numeral advances for power changes. Oswald supplies punctuation missing from the display face.
