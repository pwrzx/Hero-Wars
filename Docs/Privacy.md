# Hero Wars privacy

Hero Wars is an offline single-player tower puzzle game. The game does not create accounts, display ads, process purchases, use advertising identifiers, or send gameplay events to an analytics or multiplayer service.

The game stores your inventory, equipped cosmetics, currency, campaign progress, daily-gift date and settings locally using Unity PlayerPrefs. A second local save document helps recover damaged data. Device or operating-system backups may also include application data under the platform's own settings. The game does not operate its own cloud-save service.

Optional haptics use the device's vibration hardware. The Android vibration permission does not give access to contacts, location, photographs or microphone data. The game does not request those permissions.

Uninstalling the application or clearing its storage may delete local progress. Keep the application installed if you want to retain progress; no account recovery service is provided.

The publisher must add its real support contact and host the final policy at a public URL for the store listing. This repository document is the policy text, not a hosted service. Review the final binary and any future SDK changes before completing the stores' privacy disclosures.
